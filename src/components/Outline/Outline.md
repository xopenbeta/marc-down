# Outline.tsx

## 作用

右侧大纲面板，卡片内可在「大纲」和「设置」两个视图间切换：大纲视图展示当前文档的标题结构，设置视图将设置项内容直接嵌入卡片（不再使用弹窗）。

## 为什么这么实现

- 顶栏按钮行：左侧为文档操作（折叠源码块/导出，仅大纲视图显示），右侧为视图切换按钮（大纲/设置），激活的按钮保留 hover 深色背景
- 大纲视图：平铺列表展示所有标题，右侧 badge 显示层级数字；折叠逻辑按层级维度操作（点击某层级 badge 折叠该层级以下的所有标题）
- 设置视图：`SettingsList` 是一个纵向大列表，每个 section 是小号标题（11px 大写 muted），下面跟设置内容；沿用 `settingsAtom` + `saveSettings` 持久化，与旧弹窗行为一致
- 面板整体显隐由编辑器右上角按钮设置 `isOutlineCollapsedAtom`
- 底部字数/行数统计仅大纲视图显示
